# Casos de Uso — Urna Cidadã
## 1. Objetivo
Este documento descreve como o eleitor interage com o sistema Urna Cidadã durante uma votação simulada. Os casos de uso apresentam os objetivos do usuário, o fluxo principal de interação e as situações alternativas que podem ocorrer durante a votação.
As regras detalhadas e os requisitos funcionais do sistema estão documentados no arquivo requisitos.md.

## 2. Ator principal
Eleitor: pessoa que utiliza a urna eletrônica educativa para participar da votação simulada.

## 3. Lista de casos de uso
| Código | Caso de uso | Objetivo |
| UC01 | Iniciar votação | Começar uma sessão de votação |
| UC02 | Escolher candidato | Informar o número e conferir os dados do candidato desejado |
| UC03 | Corrigir escolha | Substituir uma escolha ainda não confirmada |
| UC04 | Escolher voto em branco | Optar por não selecionar um candidato para o cargo atual |
| UC05 | Confirmar voto | Registrar definitivamente a escolha realizada |
| UC06 | Avançar para o próximo cargo | Continuar a votação após a confirmação do voto atual |
| UC07 | Encerrar votação | Finalizar a sessão após a última confirmação |
